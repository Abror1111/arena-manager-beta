# ARENA 1.17 — free map inspection, movement and local CS2 audio

The map library and pre-match tactics screen open a separate 3D map viewer. It does not start or change a career/match, does not simulate combat, and does not load agent models or combat particle textures. Drag to pan, pinch/twist to zoom/rotate, use the A/B/base buttons, change floors, quality or the camera angle. PC also supports WASD/arrows, Q/E, wheel and Shift/right-drag. Closing or changing maps disposes the scene. Ancient Night remains a simplified scene.

Magenta awnings, umbrellas and some tree surfaces were Source2 foliage/cloth wind/AO channels interpreted as RGB color. The original mobile optimizer stripped only wind mode1; cloth uses mode2 and some static foliage retains encoded masks without that flag. A manifest derived from the original vmat metadata corrects only the affected albedo materials in nine maps. Ordinary baked wall tints remain enabled. Map binaries, texture bytes, source triangles and navigation JSON are unchanged. Future mobile derivation strips foliage mask attributes before baking instance tint.

Steering now checks directed reachability to its destination, and ignores peers behind nav-separated walls. One-way decorative ledges are excluded from cover, spacing and evasion choices when they cannot lead back to any objective/base. Source portals retain their destination identity. Nearby waypoints are skipped only if the next segment has continuous floor coverage. Repeatedly blocked allies yield by priority, walk directly to verified local floor, and can walk back before retrying. The movement watchdog starts only on an actual move request, excluding round preparation and long cover holds. No agent is relocated or teleported. The seeded stress comparison uses 11 maps ×3 seeds: fourteen prolonged blocked-motion reports before the change, zero after the final watchdog activation fix. This is not a guarantee that every possible seed is free of movement problems; intentional holding/cover still exists.

The user uploaded ARENA-CS2-AUDIO-20261021-170900.zip, but the attachment transfer tool refuses files above32MiB. That archive was NOT inspected or bundled. Settings now offer a local audio ZIP importer using the provided exporter's schema1 `ARENA-audio-export.json`. It selects bounded combat clips, verifies SHA256 in a worker, checks browser decoding, and atomically stores the usable original recordings in a separate IndexedDB database. No file is uploaded by this feature. On Android a document picker grants access to the selected ZIP; navigation remains restricted to arena.local and file:// access stays disabled. Cancelled/invalid imports preserve the prior pack and the career. Available recordings play through the bounded match mixer with stereo attenuation/limiting; missing sounds retain the procedural fallback. Imported audio stays on that device and is not included in the club JSON backup. Import validation/browser playback tests use explicitly labelled synthetic WAV fixtures, not claimed CS2 recordings. Actual supplied sound coverage remains unverified until the archive is accessible or imported on the user's device.

Install the APK over the existing app. Career schema2, club key and upgrade signer remain compatible. Physical Android file-picker/GPU behavior is not measured by desktop browser emulation; native compilation and package/signature checks complement browser tests.
