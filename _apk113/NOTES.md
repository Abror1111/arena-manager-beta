Animated fire, grenade smoke and blast effects for phones and PC.

- Original user-exported CS2 Ancient candle flame atlas with source animation timing. This is not the native Molotov particle definition.
- Floor-aware fire, persistent scorch, bounded volumetric smoke, flash glare, HE/C4 dust and sparks. Smoke extinguishes fire; HE/C4 temporarily open smoke. ARENA rendering approximates Source2.
- Existing10 authentic mobile scenes,36 weapons/equipment, source agents/animations, map-object fragments and club careers are retained. Ancient Night remains simplified3D.
- Same Android package/signing key; install over1.12 to retain your club. Android8+. All map assets included for offline play.
- Optional Windows VFX export helper reads your installed CS2 resources and produces a checked ZIP; it never writes into the installed game. Windows live export and physical Android GPU performance are not tested in the cloud.

APK signature,16K alignment, embedded files, tests, emulated phone/PC VFX, are verified before APK publication. Project-prefix/offline web checks are completed before web deployment. Original CS2 assets belong to Valve and respective owners.
