# ARENA ct26 — Sahil open CT street and layered routes

Isolated beta: /original20/?v=ct26. The old club manager and battle HUD are retained byte-for-byte in compiled CSS. The root eleven-map release, root career, production bot and previous APK are unchanged.

## Layout and movement

The 120×120 metre Sahil plan uses a Dust II reference radar for landmark arrangement: B northwest, A northeast, T south and CT north-centre. CT now starts in an open street west of the raised Short crossing, as requested. CT has separate routes through Mid/B doors and toward A via a gradual ramp. All five CT starts are under clear sky. Short crosses above the CT-to-A passage on a closed L-shaped deck with four support columns. The same X/Z can represent a lower .05 m floor or upper 4.25 m floor; actors cannot jump between levels. A Short arrives via actual stairs; A Long uses an enclosed two-door chamber and the east lane. Upper/lower B connect via stairs and Mid. Fifteen irregular main building groups and fourteen context buildings remain. This is an authored approximation of the reference, not a complete 1:1 source map.

Four double-door openings at Mid, B and the two ends of Long are drawn from the same coordinates as their collision shapes and open leaves. Ten flanking wall segments close the former standalone arches; the Long chamber has a ceiling. Visible horizontal treads, risers and retaining faces use the same floor definition as navigation and foot IK. Three stair flights have 23 treads/risers. Standing levels are A/upper Short 4.25 m, T/Long 3.20 m, Short approach 2.60 m, B/upper B tunnel 1.80 m, lower B .15 m and CT/Mid .05 m. Continuous ramps connect CT to A and T to Mid.

Navigation uses a cached two-layer metre grid with height-aware collision, sampled traversability and path smoothing. A regression preserves the first reachable grid point when an actor turns around the inside of the L-shaped Short bridge. Close arrival tolerance and an initial clearance escape prevent agents becoming trapped against nav padding. Live walking tests traverse A Short, CT A and A Long, not just precomputed path points. Lower and upper bridge paths block shots across the deck. Equipment, C4 single-held/placed logic and original analytic operator animation remain.

Player and automatic cameras remain separate. The minimum vertical field is 22 m for player tracking and 28 m for automatic action tracking in landscape. Narrow viewports use a wider minimum. The damping spring enforces the minimum even when seeded by an older close camera. Oblique angles, smooth transfers, occluder reveal and map inspection remain. These are orthographic field sizes, not perspective distances.

The west coast remains outside the playable outline, with animated vertex waves, Fresnel tint, sun highlights, foam, nearshore transparency, original white articulated gulls and moving clouds. Existing procedural texture/normal-map detail and quality controls remain. No source-game mesh, texture, audio, animation, navigation or radar is bundled or requested by this beta. Reference imagery was viewed as a guide. This describes provenance, not legal clearance.

## Saves and build

The beta keeps arena-career-original20. Root arena-career-rebuilt131 is separate. Because routes and levels changed, old20–25 active rounds restart at the same round, score and funds; current26 snapshots resume normally. A planted C4 in an older active round therefore restarts with that round, rather than being placed at an invalid location. Existing root saves and caches remain untouched.

Use npm install, npm test and npm run build. ARENA_MANAGER_OUT and ARENA_MODULE_RECEIPT optionally select build paths. Serve under /original20/. The existing original anime portrait atlas at ../ui15/anime-player-portraits.png and 30 authored audio cues at ../audio/<sha256>.(wav|mp3) are shared parent media. The source ZIP includes all reachable modules, public shell, build configuration, third-party notices and current tests; those parent media are not duplicated.

Node checks cover twenty spawn-to-site paths, six tactical routes, actual agent traversals, two completed AI rounds, separate bridge levels, blocking shots, four gate openings, ten flanking walls, camera limits and operator motion. Optional tests/render-floor26.mjs uses a running Vite dev server at ARENA_TEST_ORIGIN (default http://127.0.0.1:8221), Chromium and ARENA_FLOOR_REPORT to raycast actual rendered geometry, all 23 treads and all five open-sky CT starts. Browser checks cover old UI, roof inspection, natural movement, separate player/auto cameras, mobile landscape fit, C4 placement and offline resume. Browser emulation does not certify physical-device performance.
