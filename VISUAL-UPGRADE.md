# ARENA Manager 1.25 beta

Eleven original ARENA scenery kits now add courtyard gardens, pergolas, small kiosks, solar equipment, depot details and asymmetric stone gardens. 137 new groups fill verified open pockets across all eleven layouts. Three courtyard variants and irregular placement reduce repetition. Nearby original additions use only the project's own procedural atlas, leaf cutouts and new geometry; they no longer receive copied source-game materials.

The new footprints clear all source navigation polygons by at least 0.95 world units, avoid prior scenery and water, and sit on either existing flat ground, continuous terrain, or supported roof surfaces. Foundations follow the local grade. Existing source geometry, navigation and gameplay are retained. This is decorative, non-playable infill, not a claim that every open courtyard should become blocked.

A standalone model gallery shows the original additions separately. Eleven self-contained colour-only GLBs contain no source-game meshes, images or textures. Gameplay adds the project's original materials and foliage cards; the studio thumbnails simplify foliage to solid shapes. [Original model gallery](arena-art-125.html).

Rights scope: the new scenery is project-authored. The existing CS2-derived base maps/layouts, source textures, agents and original audio are separate assets and remain subject to their owners' rights. Adding or recolouring scenery does not establish clearance for the entire game. Replacing the remaining source assets and layouts with an independent design is a separate stage.

The 1.24 original audio set remains: 75 original effect/reload/ambient cues, four supplied original music cues, PCM compatibility, 32kHz bounded effect decoding and explosion priority. Install over the previous app to retain the club; package ID, signing identity and career schema remain. The separate case bot is untouched. Physical Android performance/output requires a device test.
