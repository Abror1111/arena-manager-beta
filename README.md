[Play on PC or phone](https://abror1111.github.io/arena-manager-beta/?v=113) · [Android APK](https://github.com/Abror1111/arena-manager-beta/releases/download/arena-1.13-beta/ARENA-1.13-beta.apk) · [Download page](https://abror1111.github.io/arena-manager-beta/download.html)

Animated original CS2 Ancient candle flame atlas, floor-aware Molotov fire, bounded ray-marched smoke, flash bursts, blast dust/sparks and persistent scorch. Smoke extinguishes fire; HE/C4 temporarily clear smoke. These are ARENA approximations, not the native Source2 particle system. The 36 weapon/equipment profiles, training armory and source-map prop physics remain. Ten authentic mobile map scenes and persistent verified downloads remain. The APK includes all maps for offline play. SAS/Phoenix source animations and existing club/5v5 careers are retained. Install over 1.12 to keep your club. Ancient Night retains source navigation and simplified 3D.
