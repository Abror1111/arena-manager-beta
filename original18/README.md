# ARENA Originals — Sahil / Operator Lab 02

A separate original coastal 3D visual sample. Does not replace the existing manager or production bot.

The scene, facade elements, canvas materials, palm geometry, water/flame/particle shaders, articulated characters, grid navigation and synthesized audio were authored for this sample. No CS2 model, texture, sound, icon, animation clip or navigation asset is imported. Three.js 0.180.0 is used under MIT; the complete notice accompanies the web build and is embedded in the downloadable HTML.

Controls: drag to orbit the overview; wheel/pinch to zoom. Separate Auto-action and Agent cameras. Click a visible agent label or choose a roster entry in Agent mode. Effects menu: grenade, smoke, incendiary, flash, C4. Sound requires a user click. Pause, HD/ECO and fullscreen controls included. The top **Operator** button opens an isolated close-up studio; its selector exposes ten motion states and a continuous cycle. Drag the studio view to inspect the front and back.

This is an 85-second looping demonstration with independently navigating agents and staged events, not a finished competitive AI or integrated career match. The characters and sound design are original procedural prototypes; no claim of scanned/captured studio assets, final AAA quality or legal certification is made.

The original fitted operator has 20 animated rig transform nodes, including weapon/prop transforms, and approximately 30,600 triangles. It uses articulated rigid mesh parts with fitted geometry and analytic two-bone arm/leg IK; it is not a motion-capture or skinned production-character asset. Geometry includes shaped clothing, woven material maps, seams, webbing, carrier pouches, radio wiring, helmet attachments, face details, gloves/fingers, boots/laces, holster, a detailed original carbine, magazine, optic and sidearm. Most mesh parts share geometry and are instanced across the live ten agents. The studio renders on its own camera/light layer.

Locomotion follows measured movement in local forward/sideways directions; stance/swing phases and knee poles determine the feet, while upper-body aim, breathing and recoil are layered on top. Reload moves the supporting hand through magazine-well, pouch and charging-handle targets. A held grenade disappears at release; the live projectile launches after the matching wind-up. The studio also exposes crouch, plant and sidearm transitions. In the live demonstration, destination scoring uses entry/support/marksman/anchor/flank roles, ally goal spacing and recent-goal memory; visible targets have reaction delay and short bursts, and magazine/reserve accounting is finite. These heuristics are not a claim of professional-player intelligence or learned behavior.

Selected-agent viewing softly fades obstructing canopy along the camera-to-agent line; map geometry and other camera modes are retained. This targeted reveal is limited to the original leaf materials.

Checks: `npm test` validates finite transforms and independent arm/leg link lengths across ten motion states. `tests/browser.mjs` exercises actual WebGL, all ten motion selections, twenty studio/map layout combinations, live navigation/shooting, effects, sound, pause and an offline standalone HTML context. `tests/production.mjs` checks the old showcase service-worker upgrade and preservation of the manager cache using the local production-prefix fixture; `tests/canopy.mjs` checks the final reveal shader and live effects. Browser scripts use the environment's Chromium at `/usr/bin/chromium` and local test servers. Physical-device performance and final artistic production quality remain to be evaluated.

Build from this directory with `node build.mjs`; dependencies resolve to the existing pinned Three.js/esbuild installation. Default output is `/dev/shm/arena-operators19-build` to avoid modifying the large manager build or filling the workspace disk. `ARENA_SHOWCASE_OUT` can override the output directory. The output HTML embeds its code/material generation; no CDN assets are needed. The optional subdirectory service worker is restricted to `/original18/` and uses its own cache namespace.

The downloadable HTML can be opened by a WebGL-capable browser. The managed test browser blocks `file:` navigation; a no-network browser context rendering the exact HTML is used to verify self-containment instead. Physical Android/iOS devices have not been certified. Relative links to the separate notice document require the accompanying file or the hosted version; its full notice is also embedded in the HTML itself.

Source legality of the main manager's legacy CS2 materials is a separate unresolved matter; this sample does not clear those distributions.
