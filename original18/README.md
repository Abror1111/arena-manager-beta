# ARENA Sahil motion20

The first standalone demo UI is restored unchanged. The online /original18/ entry now opens the full existing club-manager UI at ../original20/. This downloadable HTML remains a self-contained single-map visual demonstration with staged events; the manager uses the actual Match engine.

Original author-made procedural district, 20-joint rigid articulated operators with analytic IK, world-anchored stance feet, turn easing, low-ready rifle/pistol and objective handling. Original geometry, canvas textures, particles and synthesized audio. No source-game exported media or navigation. Not mocap, not CS2-equivalent animation, and not legal clearance.

Install dependencies with npm install, then npm test and npm run build. ARENA_SHOWCASE_OUT selects output directory. tests/motion20.mjs independently checks planted-foot slip. Three.js MIT notice is embedded in the HTML.
