# ARENA Studio UI15

The main game now composes each manager screen and modal into viewport-height columns. Swipe horizontally, use the Previous / Next controls, or focus a field with the keyboard to reveal its page. Content is measured in place with ResizeObserver; inputs and audio state have one DOM instance and retain their identity while the viewport changes.

The transfer market and weapon shop are the only vertical scroll regions. Home, squad, training, season, tactics, maps, settings, help, camera, player selection, commands, audio and results use horizontal pages. Small landscape phones retain 44px controls, and keyboard input gets extra usable height. Safe areas, live visual viewport height, reduced motion, book and tabletop hinges are handled explicitly.

The transfer market, club and match HUD use a local atlas of 16 original, generated anime portraits of fictional adult competitors. These are fictional game characters drawn with crisp outlines and cel shading. Player identities are stable across manager screens and matches. Atlas: `ui15/anime-player-portraits.png`, SHA256 `959acbc1ec430f3d6cbc70aaa6a961d67033535e60183e0b1a8cded17760a5de`. The original generated PNG is retained in the workspace.

All 11 approved source maps, their completed surroundings, collision revision 14, audio, match simulation and career storage schema remain unchanged. This release updates the web game. The previously signed APK has not been rebuilt.

Validation uses actual React screens in Chromium touch emulation: 23 viewport sizes across all 8 manager screens, card bounds on every horizontal page, no unintended vertical scrollers, 44px controls, 29 match HUD/sheet sizes, book/tabletop hinge emulation, training, transfers, lineup, settings, audio controls, economy, camera selection, round result fixture and match resume. The production project-prefix build is also checked with real source-map WebGL and service-worker offline reload. This is browser emulation and local production-build validation, not certification on every physical phone or Safari.
